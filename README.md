# ZeichnenDauerhaft

Ein Visual-Studio-Projekt zur Einführung in die dauerhafte Darstellung grafischer Zeichnungen innerhalb einer Benutzeroberfläche.

## Beschreibung

Das Projekt **ZeichnenDauerhaft** beschäftigt sich mit den Grundlagen der dauerhaften Darstellung von Zeichnungen in einer grafischen Anwendung. Im Mittelpunkt steht die Erhaltung gezeichneter Inhalte, auch wenn das Fenster aktualisiert, verschoben oder neu gezeichnet wird.

## Funktionen

- Zeichnen grafischer Elemente
- Dauerhafte Darstellung von Zeichnungen
- Neuzeichnen grafischer Inhalte bei Fensteraktualisierungen
- Verwendung grafischer Zeichenmethoden
- Grundlagen der Ereignisbehandlung beim Zeichnen

## Technologien

- Microsoft Visual Studio
- .NET
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/ZeichnenDauerhaft.git
   ```

2. Die Datei `ZeichnenDauerhaft.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.

## Ziel

Das Projekt dient dem Verständnis der dauerhaften Darstellung grafischer Inhalte. Dabei werden grundlegende Konzepte der Grafikprogrammierung, der Aktualisierung von Zeichenflächen und des erneuten Zeichnens von grafischen Elementen kennengelernt.
